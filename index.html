現在の目標 · Post-FP

M1 Reliable Standard Riichi

First Playableは完了。次は一般的な日本式リーチ麻雀のローカル対局を、開始から最終結果まで信頼できる品質で完走できる状態へ。

  1. P1 · 局間ownership確定点数・供託の一度だけの引き継ぎと、明示的な次局開始をHeadlessで検証。
  2. P2 · 有限の対局局進行・連荘・本場・流局精算・終了を統合し、Unityで1 Human + 3 Botsの対局を通す。
  3. Kanの対局統合Kan前に表示の順序・遷移を検討するplanning gateを通し、槓・嶺上・槍槓・槓ドラを統合。
  4. Standardの不足を閉じる残る役・役満・裁定・境界ケースから採用範囲とDefaultを決め、合法性から表示まで統合。
  5. M1の統合信頼性Core・Unity・新しいWindows private candidateで有限対局、回帰、操作性・既知制約を確認。

Roadmapの主軸です。phase数は完成率・工数・ETAを表しません。具体仕様と着手は各phaseのPlanning / Human Reviewに従います。

P1 / #113が最初のIssue-design済みsliceです。実際の着手・レビュー状態は下のGitHub表示で確認できます。P2以降のImplementation Issueは今後のPlanningで具体化します。

UI / QOL・素材・private playtest・開発運用は実需要に応じた横断候補です。主軸の完了を代替しません。
